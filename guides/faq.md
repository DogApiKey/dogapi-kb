# 常见问题 (FAQ)

## 账号相关

### Q: 如何获取 API Key？

A: 
1. 访问 DogAPI 控制台
2. 登录您的账号
3. 进入 "令牌" 页面
4. 点击 "创建新令牌"
5. 复制生成的 Key（请妥善保管，只显示一次）

### Q: API Key 丢失了怎么办？

A: 您可以在控制台重新创建一个新的令牌。出于安全考虑，我们无法恢复已丢失的 Key。

### Q: 一个账号可以创建多少个 Key？

A: 默认支持创建 10 个令牌。如需更多，请联系客服。

## 使用相关

### Q: 支持哪些模型？

A: 我们支持主流的 LLM 模型，包括：
- OpenAI: GPT-4o, GPT-4o-mini, GPT-3.5-turbo
- Anthropic: Claude 3.5 Sonnet, Claude 3 Haiku
- Google: Gemini Pro, Gemini Flash
- 更多模型请查看控制台模型列表

### Q: 请求报错 401 Unauthorized

A: 请检查：
1. API Key 是否正确
2. Key 是否已过期
3. 请求头格式是否正确：`Authorization: Bearer sk-xxxxx`

### Q: 请求报错 429 Too Many Requests

A: 您的请求频率超过了限制。解决方案：
1. 降低请求频率
2. 实现请求重试机制（建议指数退避）
3. 联系客服提升配额

### Q: 请求报错 500 Internal Server Error

A: 这通常是上游服务的问题。请：
1. 稍后重试
2. 尝试使用其他模型
3. 如果持续出现，请联系客服

## 充值相关

### Q: 如何充值？

A: 
1. 登录控制台
2. 进入 "充值" 页面
3. 选择充值金额
4. 完成支付

### Q: 余额不足会怎样？

A: 余额不足时 API 请求会返回 402 错误。请及时充值以避免服务中断。

### Q: 支持哪些支付方式？

A: 目前支持支付宝和微信支付。
