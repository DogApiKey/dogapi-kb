# DogAPI 新手入门指南

欢迎使用 DogAPI！这是一个一站式的 AI 模型服务平台，让你像使用自来水一样方便地使用各种顶尖 AI 模型。不需要技术背景，跟着下面的步骤，几分钟就能上手。

---

## 1. 注册账号

打开 DogAPI 的首页，点击右上角的 **注册** 按钮。

你需要填写：

| 项目 | 说明 |
|------|------|
| 用户名 | 给自己取一个名字，方便记忆即可 |
| 密码 | 建议使用字母 + 数字的组合，至少 6 位 |
| 邮箱 | 部分服务可能需要邮箱验证，建议填写真实邮箱 |
| 邀请码 | 如果朋友推荐你来的，填上邀请码双方都能获得奖励哦 |

> 小贴士：注册完成后系统可能会自动为你创建一个默认的令牌（API Key），可以直接跳到第 4 步开始体验。

---

## 2. 获取 API Key

API Key 就是你的"通行证"，有了它才能调用 AI 模型。

**操作步骤：**

1. 登录后进入 **控制台**
2. 点击左侧菜单的 **令牌** 页面
3. 点击 **添加令牌**
4. 给令牌取个名字（比如"我的手机"、"办公电脑"）
5. 可以设置额度上限（防止意外超支），也可以选择"无限额度"
6. 点击 **保存**
7. **重要：** 点击令牌卡片上的复制按钮，把以 `sk-` 开头的密钥保存好

> 安全提示：API Key 就像你的银行卡密码，不要分享给他人，也不要发到公开的地方。如果不小心泄露了，可以随时禁用旧的并重新创建一个。

---

## 3. 选择模型

DogAPI 提供了市面上主流的 AI 模型，你可以根据需要自由选择：

| 模型 | 特点 | 适合场景 |
|------|------|----------|
| GPT-4o | OpenAI 旗舰模型，全能选手 | 日常对话、写作、分析 |
| GPT-5 | OpenAI 最新模型 | 复杂推理、专业任务 |
| Claude 3.5 Sonnet | Anthropic 出品，擅长长文理解 | 长文档分析、翻译、创作 |
| Claude 3.7 Sonnet | Claude 最新版本，支持深度思考 | 需要深入分析的复杂问题 |
| Gemini 2.5 Pro | Google 最新模型 | 多模态任务、综合分析 |
| Gemini 2.5 Flash | 速度快、性价比高 | 日常快速问答 |
| DeepSeek-V3 | 国产优秀模型 | 中文对话、编程辅助 |
| DeepSeek-R1 | 深度推理模型 | 数学、逻辑推理 |

> 不确定选哪个？先试试 GPT-4o 或 Gemini 2.5 Flash，它们是性价比很高的入门选择。

## 4. 第一次 API 调用

拿到 API Key 和选好模型后，你就可以开始使用了。

**最简单的验证方式：** 打开终端或命令行工具，粘贴以下内容（把 `你的API密钥` 替换成你的真实 Key）：

```bash
curl https://你的域名/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer 你的API密钥" \
  -d '{
    "model": "gpt-4o",
    "messages": [
      {"role": "user", "content": "你好，请用一句话介绍一下你自己"}
    ]
  }'
```

如果返回了 AI 的回复，恭喜你，调用成功了！

> 别担心记不住这些参数，下面第 5 步介绍的客户端会帮你自动生成请求，你只需要打字聊天就行。

---

## 5. 在客户端中使用

你不需要每次都手动写请求。有很多好用的客户端可以帮你像聊天一样使用 AI，以下是最受欢迎的几款：

### Cherry Studio（桌面客户端，推荐）

1. 下载安装 [Cherry Studio](https://www.cherry-ai.com/)
2. 打开设置，找到"模型服务商"或"API 设置"
3. 将 API 地址填为 DogAPI 的地址
4. 将 API Key 填为你刚才获取的 `sk-` 密钥
5. 回到主界面，选择模型，开始聊天

### Aion UI（网页客户端）

1. 打开 [Aion UI](https://github.com/iOfficeAI/AionUi/)
2. 在设置中配置 API 地址和 Key
3. 选择喜欢的模型，直接开始对话

### ChatGPT Next Web / LobeChat

1. 打开应用，进入设置页面
2. 找到"接口地址"或"API Base URL"选项
3. 填入 DogAPI 的服务地址
4. 填入你的 API Key
5. 保存设置，选择模型即可开始使用

> 小贴士：以上客户端大多支持同时接入多个服务商。你可以把 DogAPI 作为其中一个，随时切换对比不同模型的效果。

## 6. 查看用量和余额

DogAPI 提供了直观的仪表盘，帮你随时了解使用情况：

**登录控制台后，你可以看到：**

- **余额信息** -- 你账户中剩余的可用额度
- **使用统计** -- 每日/每周的调用次数和 Token 消耗量
- **详细日志** -- 每一次 API 调用的记录，包括使用的模型、消耗的额度、响应时间等
- **订阅信息** -- 如果你购买了套餐，可以查看套餐剩余量和有效期

**充值方式：**

- **在线充值** -- 支持支付宝、微信等国内常用支付方式，也支持信用卡
- **兑换码** -- 如果你有朋友分享的兑换码，在"充值"页面输入即可到账
- **签到领额度** -- 每天签到可以领取免费额度，积少成多

> 省钱技巧：DogAPI 支持订阅套餐，如果你使用量比较大，购买套餐通常比按量付费更划算。

## 7. 遇到问题？

别着急，大部分问题都有简单的解决办法：

### API 调用返回错误

| 提示信息 | 可能原因 | 解决方法 |
|----------|----------|----------|
| 401 Unauthorized | API Key 无效或过期 | 检查 Key 是否正确，或重新创建一个 |
| 403 Forbidden | 没有权限使用该模型 | 确认你的令牌是否关联了这个模型 |
| 429 Too Many Requests | 请求太频繁 | 稍等一会儿再试 |
| 余额不足 | 额度用完了 | 去充值或购买套餐 |

### 找不到想要的模型

部分模型可能需要管理员为你开通权限。如果在模型列表中没看到你需要的模型，可以联系平台客服。

### 忘记密码

在登录页面点击"忘记密码"，输入注册时使用的邮箱，系统会发送重置链接到你的邮箱。

### 想更安全？

你可以在个人设置中开启 **两步验证（2FA）**，使用手机上的认证器应用（如 Google Authenticator）扫码绑定。开启后每次登录都需要输入动态验证码，大大提升账号安全性。

### 其他问题

- 查看控制台中的 **公告** 栏，了解平台最新动态
- 如果平台有在线客服或社群，随时提问，大家都很乐意帮忙
