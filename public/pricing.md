# 价格说明

DogAPI 采用按量计费模式，用多少扣多少，没有月费门槛。以下是计费、充值和查看用量的详细说明。

---

## 计费方式

### 按量计费

DogAPI 使用额度（Quota）作为统一的计费单位。每次 API 调用会根据以下因素消耗额度：

- **模型类型**：不同模型的单价不同（如 GPT-4o 比 GPT-4o-mini 消耗更多额度）
- **输入 Token 数**：您发送的文本长度
- **输出 Token 数**：模型返回的文本长度
- **图片 / 音频 / 视频**：按生成内容的数量或时长计费

简单来说，消耗的额度 = 输入 Token x 模型输入单价 + 输出 Token x 模型输出单价。

### 额度与货币换算

额度可通过控制台查看当前的换算比例。默认情况下：

- 1 美元 = 500,000 额度

您可以直接在控制台将额度显示为 Token 数量、美元或人民币。

### 分组计费

不同用户分组可能有不同的计费倍率：

- **默认分组**：标准倍率
- **VIP 分组**：享受优惠倍率
- **自动分组**：系统自动为您选择最优分组

倍率越高，同样操作消耗的额度越多。升级分组可以享受更低的单价。

## 如何查看用量

### 控制台查看

登录用户控制台后，您可以看到：

- **总额度**：当前账户剩余可用额度
- **已用额度**：历史累计消耗
- **请求次数**：总 API 调用次数
- **日统计**：按日期查看每日使用量和消耗额度
- **详细日志**：每次调用的模型、Token 数、消耗额度、响应时间等

### API 查询

您也可以通过 API 接口实时查询用量：

- 查询余额：使用您的令牌调用查询接口
- 查询账单：查看详细的使用记录和统计数据

### 额度预警

您可以设置额度预警阈值，当余额低于设定值时，系统会通过以下方式通知您：

- 邮件通知
- Webhook 推送
- Bark 推送
- Gotify 推送

## 如何充值

### 方式一：在线支付

支持多种在线支付方式（具体以实际可用为准）：

- **支付宝**：最常用的支付方式
- **微信支付**：扫码即可完成支付
- **Stripe**：支持国际信用卡 / 借记卡
- **Apple Pay**：iPhone / Mac 用户便捷支付
- **Google Pay**：Android 用户便捷支付

操作步骤：
1. 登录控制台，进入充值页面
2. 选择充值金额（通常提供 1 / 5 / 10 / 20 / 50 / 100 等档位）
3. 选择支付方式
4. 完成支付，额度实时到账

### 方式二：兑换码

如果您有兑换码，可以在充值页面输入兑换码，即可获得对应额度。

- 兑换码一般通过活动发放或由管理员分配
- 每个兑换码仅可使用一次
- 兑换码可能有有效期限制，请及时使用

### 方式三：订阅套餐

部分用户可以选择订阅套餐，按月获取固定额度：

- 适合稳定用量的用户
- 套餐内额度每月自动重置
- 支持多种支付方式

## 优惠活动

### 每日签到

每日签到可获得随机额度奖励，坚持签到积少成多！

- 每天可签到一次
- 奖励额度随机，连续签到有机会获得更多
- 签到入口在控制台首页

### 邀请好友

邀请好友注册，双方都能获得奖励额度：

- 分享您的专属邀请码或邀请链接
- 好友成功注册后，您和好友都可获得额度奖励
- 部分用户还可享受邀请佣金：好友充值时您可获得一定比例的返佣

### 新用户福利

新注册用户可能获得平台赠送的体验额度，具体以注册时的实际活动为准。

## 常见问题

### Q: 我的额度用完了吗？怎么查看？

登录控制台即可在首页看到剩余额度。您也可以设置额度预警，余额不足时会自动通知。

### Q: 充值后多久到账？

在线支付和兑换码充值一般是实时到账。如遇延迟，请稍等几分钟后刷新页面。

### Q: 额度会过期吗？

额度本身不过期，但兑换码可能有使用期限。订阅套餐的额度在套餐周期结束时未使用部分会清零。

### Q: 不同模型的价格差别大吗？

是的，不同模型价格差异较大。轻量模型（如 GPT-4o-mini）消耗的额度远低于旗舰模型（如 GPT-4o）。建议根据实际需求选择合适的模型，详情请参考[支持的模型](./models.md)。

### Q: 如何降低使用成本？

- 优先使用性价比高的模型（如 GPT-4o-mini、DeepSeek V3）
- 控制输入长度，避免发送不必要的上下文
- 设置令牌额度上限，防止意外超支
- 坚持每日签到获取免费额度
- 参与邀请好友活动获取额外奖励
